# Tests for ticket #27: work out the prizes a ticket number wins

Written from the ticket's "Done when" only, before the code exists.

**Where these run:** everything runs on the Mac with `fvm flutter test`, no device. The ticket adds only the prize rules, with no screen, camera or internet, so a plain Dart test on fixed numbers proves every behaviour criterion, and an emulator or phone would add nothing. There are no integration tests and no manual steps.

## What the tests call

There is nothing on screen to look at, so the tests call the rules directly. The implementer must provide:

- A file `app/lib/shared/prize_check.dart`.
- In it, a function `prizesWon(ticketNumber, winningNumbers)`:
  - `ticketNumber` is the six digits as a `String`, so a number starting with `0` keeps its zero.
  - `winningNumbers` is a `List<String>` of the province's 18 winning numbers, in order from Đặc biệt down to Giải Tám, as the ticket says: ĐB (6 digits), Nhất, Nhì, Ba x2, Tư x7 (5 digits), Năm, Sáu x3 (4 digits), Bảy (3 digits), Tám (2 digits).
  - It gives back every prize won, as a list (any iterable) of items that each have a `name` (`String`) and an `amount` (`int`, in đồng). A Dart record or a small class both pass. No prize gives back an empty list.
- The names are the table's, exactly: `Giải Đặc biệt`, `Giải Nhất`, `Giải Nhì`, `Giải Ba`, `Giải Tư`, `Giải Năm`, `Giải Sáu`, `Giải Bảy`, `Giải Tám`, `Giải may mắn`, `Giải khuyến khích`. Amounts are plain numbers, e.g. 2.000.000.000đ is `2000000000`.

## How the tests prove it

- **"The result is X"** means exactly that one prize, nothing more. Only the ĐB example says "and nothing else" in words, but a check that also gave, for example, Giải Tám would be telling the person a wrong amount.
- **"Lists both"** for 921443 accepts the two prizes in either order, because the ticket doesn't give an order.
- **The real results are partial.** The ticket gives only ĐB, Nhất, Bảy and Tám for Bạc Liêu 10/11, and ĐB and Tám for Hồ Chí Minh 09/11. The other numbers of the 18 are made up so that no ticket in these tests matches them. The outcome of each test therefore depends only on the numbers the ticket gives.
- **The made-up set** gives each tier numbers whose endings differ from every other tier's, and each ticket differs from ĐB in more than one digit, so each ticket can win only its own tier. For the tiers with more than one number (Ba, Tư, Sáu), the ticket matches the last number of the tier, not the first, so a check that only looks at the first number fails.

## Running the tests

From `app/`:

```sh
fvm flutter test test/prize_check_test.dart
```

They are also picked up by `fvm flutter test`, with the other widget tests.
