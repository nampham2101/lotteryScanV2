Manual steps for ticket #8, from docs/tests/8.md. Run on 2026-11-04.

WHERE EACH CHECK RAN

The camera tests and these manual steps ran on Nam's real Pixel 7 (Android 17), by
Nam's decision, not on the Pixel_10 emulator. The emulator's back camera shows a still
scene, so "it shows a live camera picture" and the checks built on it can't pass there
reliably (see second-run.txt). The phone was held in the hand so the picture moved.

The home screen and portrait lock tests ran on the Pixel_10 emulator: the portrait lock
tests fake turning the phone, which a real phone can't do.

Run 1 on the phone (phone-camera-tests-run-1.txt) had 11 passed, 1 failed. Android's
question had gone before the test could tap "While using the app", and the camera
started before the test tapped anything. The most likely cause is a person tapping
Allow by hand; the phone's log can't prove it. Run 2 (phone-camera-tests-run-2.txt),
with nobody touching the screen, had 12 passed, 0 failed.

The steps were driven with adb (real taps sent to the phone) and uiautomator, from a
fresh install built with `fvm flutter build apk --debug`. Nothing was typed by hand.
